🗣️ Der Redefluss. 🎯 Goal: To automate the use of colloquial German phrases. This trainer is designed to help you break through the language barrier, enabling instant reactions to suggestions and fluent dialogue - perfect for sounding like a local in Zurich and beyond.


# 🇨🇭 Der Redefluss

**Der Redefluss** is an interactive web trainer for spoken German (Zurich context). The app is designed to improve speech fluency and automate the use of common phrases in daily communication.

---

## ✨ Key Features

* **🗣️ Phrase Training:** Over 150 useful phrases for real-life situations.
* **🌍 Multi-language Support:** Instant translation of German phrases into:
    * 🇺🇦 Ukrainian
    * 🇹🇷 Turkish
    * 🇸🇴 Somali
    * 🇮🇷 Persian (Farsi) + RTL support
    * 🇿🇦 Afrikaans
* **📱 PWA (Progressive Web App):** The app can be installed on iOS and Android as a native application (Add to Home Screen).
* **⚡ Lightweight:** Built with pure HTML, CSS, and JavaScript (Vanilla JS) without heavy frameworks.
